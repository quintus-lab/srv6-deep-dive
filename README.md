# SRv6 Deep Dive

A set of SRv6 experiments on Cisco IOS XR: 24 videos, slides, text pages, and lab files. Each experiment has a record.

Web page: https://quintus-lab.github.io/srv6-deep-dive/

## Contents

- The web page, in English and Traditional Chinese.
- The slides, as PDF files.
- The lab files: the topology, the router configurations, and the CE host addresses.

## Videos

This repository has no video files. The videos will be on YouTube. The links will appear on the web page.
